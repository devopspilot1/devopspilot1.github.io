# Domain 4: Serving and Scaling Models

← [Back to PMLE Learning Path](../index.md)

<small>Official exam weight: approximately 20%</small>

## Official objectives

### 4.1 Serving models

- Deploy batch and online inference using appropriate services such as Agent Platform, Model Garden, Cloud Run, and GKE.
- Package and serve models such as PyTorch and XGBoost using prebuilt or custom containers.
- Organize and version models in Gemini Enterprise Agent Platform Model Registry.
- Implement A/B testing and canary deployments to compare model versions.
- Develop inference preprocessing and postprocessing.

### 4.2 Scaling online model serving

- Manage and serve features with Agent Platform Feature Store.
- Deploy models to public and private endpoints.
- Choose CPU, GPU, TPU, or edge hardware.
- Scale the serving backend based on throughput, including Agent Platform Inference and containerized serving.
- Tune models for production training and serving requirements.
