# Domain 1: Architecting Low-Code AI Solutions

← [Back to PMLE Learning Path](../index.md)

<small>Official exam weight: approximately 13%</small>

This domain tests your ability to choose and build low-code AI solutions that fit a business problem. It is broader than MLOps: you must recognize when SQL-based ML, AutoML, a prebuilt AI API, or a foundation model is the right approach.

## Official objectives

### 1.1 BigQuery ML and AutoML on Gemini Enterprise Agent Platform

Prepare to:

- Match classification, regression, forecasting, and clustering tasks to appropriate model types.
- Perform feature engineering and feature selection in BigQuery ML.
- Generate predictions with BigQuery ML.
- Train models using Agent Platform AutoML.
- Fine-tune Gemini models using BigQuery.

### 1.2 Google Cloud AI APIs and foundation models

Prepare to:

- Select models from Gemini Enterprise Agent Platform Model Garden.
- Choose industry APIs such as Document AI, Vision, and Translate.
- Build or tune solutions using Gemini, Imagen, Veo, and models as a service in Model Garden.
- Balance cost, latency, and availability in Gemini-based applications.
