# Domain 5: Automating and Orchestrating ML Pipelines

← [Back to PMLE Learning Path](../index.md)

<small>Official exam weight: approximately 18%</small>

## Official objectives

### 5.1 Develop end-to-end ML pipelines

- Validate data and models.
- Build and orchestrate pipelines using managed or unmanaged services, templates, or custom solutions.
- Understand Agent Platform Pipelines, Managed Service for Apache Airflow, and Ray on Agent Platform.
- Ensure preprocessing is consistent between training and serving.

### 5.2 Automate model retraining

- Determine an appropriate retraining policy.
- Deploy models through continuous integration, continuous delivery, and continuous training (CI/CD/CT) pipelines, including Cloud Build.

## Exam focus

Understand the distinction between a standalone training job and a repeatable multi-step pipeline. Be able to choose managed or self-managed orchestration, determine when retraining should occur, and explain how CI/CD/CT reduces manual and inconsistent model releases.
