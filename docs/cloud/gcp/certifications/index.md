## Certification vs. certificate vs. skill badge

These Google Cloud credentials are different:

| Credential | How it is earned | What it demonstrates |
|---|---|---|
| Certification | Pass a proctored certification exam | Role-based professional knowledge and skills |
| Certificate | Complete the designated certificate learning program | Structured learning for a career-oriented skill area |
| Skill badge | Complete the required learning activities and hands-on assessment | Practical ability in a focused Google Cloud product or task |

Read Google's [credential overview](https://cloud.google.com/learn/training/credentials) for details. A Google Skills skill badge is valuable hands-on evidence, but it is not the same as passing a Google Cloud certification exam.

## Recommended preparation workflow

1. Choose a certification based on your target role and current experience.
2. Read the latest official exam guide and note every objective.
3. Follow the corresponding Google Skills learning path.
4. Practise the services in a temporary lab project or a controlled personal project.
5. Use DevOpsPilot guides to reinforce implementation, verification, troubleshooting, and cleanup.
6. Revisit the exam guide before booking the exam; product names and objectives can change.
